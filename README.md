# RangkaianKu

PWA belajar & simulasi rangkaian listrik sederhana. Dibuat untuk HP: kanvas rangkaian, pustaka komponen, simulasi DC, penyimpanan lokal.

- `index.html` — aplikasi
- `sim.js` — mesin simulasi (MNA DC)
- `core.js` — validasi & penyimpanan aman
- `selfcheck.js` — uji mandiri saat aplikasi dibuka
- `test/sim.test.js` — uji mesin (`node test/sim.test.js`)

Buka `index.html` lewat server statis apa pun, lalu "Tambahkan ke layar utama".
